# 🧮 Linear Algebra Matrix Calculator

A lightweight, fast, and dependency-free Matrix Calculator built entirely from scratch using **C++** and the raw **Win32 API**. 

This project implements procedural programming best practices to solve complex linear algebra operations without relying on external mathematical libraries.

## ✨ Features
* **Basic Operations:** Matrix Addition, Subtraction, and Multiplication.
* **Matrix Properties:** Calculate Determinant, Trace, Transpose, and Inverse.
* **Symmetry Check:** Instantly verify if a matrix is symmetric.
* **Solving Linear Systems:** 
  * Cramer's Rule
  * Gauss-Jordan Elimination
* **Custom Win32 GUI:** A clean, responsive, and standalone graphical user interface.

## 🚀 Compilation & Execution
To compile the project using MinGW (g++), run the following command in your terminal:

`g++ main.cpp MatrixMath.cpp -o MatrixApp -lgdi32`

Then run the executable:

`.\MatrixApp`
